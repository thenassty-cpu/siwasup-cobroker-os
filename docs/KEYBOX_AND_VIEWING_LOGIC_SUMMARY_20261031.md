## 1. กฎการจัดคิวเปิดบ้านต่อ 1 หลัง: "สูงสุดวันละ 2 รอบ (ครึ่งวันเช้า / ครึ่งวันบ่าย)"
เพื่อให้เอเจนท์มีเวลาพาลูกค้าเดินชมบ้าน และมีเวลา **ตั้งกล้องถ่ายทำคอนเทนต์ (TikTok / Reels / รีวิวบ้าน)** โดยไม่ชนกันหน้าบ้าน และสอดคล้องกับข้อจำกัดบ้าน NPA ที่มักถูกตัดไฟ (ดูตอนค่ำไม่ได้):
* **🌅 รอบครึ่งวันเช้า (`09:00 – 12:30 น.` | 3.5 ชั่วโมง):**
  * เอเจนท์มีเวลาถ่ายคอนเทนต์ + พาลูกค้าชมบ้านอย่างไม่เร่งรีบ
* **⏸️ ช่วงพักส่งไม้ต่อ (`12:30 – 13:30 น.` | Buffer 1 ชั่วโมง):**
  * ระบบใช้เช็กรูปถ่ายการคืนกุญแจของรอบเช้า ก่อนส่งรหัสให้รอบบ่าย
* **🌇 รอบครึ่งวันบ่าย (`13:30 – 17:00 น.` | 3.5 ชั่วโมง):**
  * เปิดบ้านและถ่ายคอนเทนต์ช่วงบ่ายก่อนแสงธรรมชาติหมด
* **🚫 ถ้ามีคนที่ 3 ขอเปิดบ้านหลังเดียวกันในวันนั้น:** ระบบบล็อกและบังคับปัดไปจองวันถัดไปอัตโนมัติ

## 2. การบริหารตู้กุญแจที่ออฟฟิศ (ท่าข้าม 12) สำหรับเฟสแรก (6–10 คน)
เนื่องจาก **ออฟฟิศเปิดทำการวันจันทร์–เสาร์** และ **บริเวณออฟฟิศคือบ้านพักของคุณกูล**:
* **ในเวลาทำการ (จันทร์–เสาร์):** เอเจนท์มารับ/คืนกุญแจที่ออฟฟิศกับพี่ลิลลี่ได้โดยตรง หรือเรียก **Messenger** วิ่งส่งกุญแจไปที่บ้านเอเจนท์ (แก้ปัญหาเอเจนท์อยู่ไกล เช่น สายไหม บางใหญ่)
* **นอกเวลาทำการ / วันอาทิตย์:** ใช้ **Smart Keybox หน้าออฟฟิศ**
  * เมื่อกล่องถูกจองแล้ว ระบบขึ้นสถานะ **`RESERVED`** ตัดสิทธิ์คนถัดไปให้เลื่อนมารับที่ออฟฟิศในเวลาทำการวันถัดไป หรือใช้ Messenger จัดส่ง

## 3. โฟลว์ส่งไม้ต่อกรณี "บ้านหลังเดียวกัน เปิดเช้า-บ่าย" (Relay Keybox)
ป้องกันปัญหาเอเจนท์เช้า-บ่ายนัดเจอกันเองแล้วมาสาย ปาดลีดหน้าบ้าน โยนความผิดเรื่องกุญแจหาย หรือภาคเช้าแกล้งเปลี่ยนรหัสหนีภาคบ่าย:
* **อุปกรณ์ที่ใช้ (Dual-Use):** ใช้ **Smart Keybox รุ่นมีห่วงคล้องพกพา (รองรับแอป TTLock / Tuya + Offline Dynamic OTP ราคา ~1,100–1,500 บาท)**
  * **วันปกติ (ไม่มีคิวเช้าต่อบ่าย):** คล้องไว้ที่รั้วหน้าออฟฟิศท่าข้าม 12 เป็นตู้จ่ายกุญแจนอกเวลาได้ทันที
  * **วันที่มีคิวเช้าต่อบ่ายในบ้านหลังเดียวกัน:** พี่ลิลลี่ปลดจากรั้วหน้าออฟฟิศ ส่งให้เอเจนท์ภาคเช้าพกติดไปพร้อมกุญแจหลัก
* **ลำดับขั้นตอน:**
  1. **พี่ลิลลี่เป็น Master Admin คนเดียวที่คุมรหัสผ่านแอป:** เอเจนท์ภาคเช้าเปลี่ยนรหัสเองไม่ได้ 100%
  2. **จบภาคเช้า (`12:00–12:30 น.`):** เอเจนท์ภาคเช้าล็อกบ้าน เอาพวงกุญแจหลักใส่ใน Smart Keybox คล้องรั้วหน้าบ้าน กดปิดฝา และถ่ายรูปส่งในระบบ -> จบงานแยกย้ายทันที
  3. **ระบบป้องกันพี่ลิลลี่โอเวอร์โหลดตอนพักเที่ยง:**
     * แยก **ตะกร้าด่วน (เฉพาะบ้านที่มีคิวบ่ายต่อ ซึ่งมีแค่ 1–2 หลัง)** ออกจาก **ตะกร้าทั่วไป (ไม่มีคิวบ่ายต่อ ตรวจตอนบ่ายได้)**
     * เมื่อคนเช้าอัปโหลดรูปครบ ระบบส่งรหัส OTP ชุดของภาคบ่ายให้เอเจนท์ภาคบ่ายอัตโนมัติ
  4. **จบภาคบ่าย (`16:30–17:00 น.`):** เอเจนท์ภาคบ่ายล็อกบ้าน แล้วหิ้วทั้ง **"พวงกุญแจหลัก + กล่อง Smart Keybox"** กลับมาส่งคืนพี่ลิลลี่ที่ออฟฟิศ (ไม่ทิ้งกล่องค้างคืนหน้าบ้าน NPA ป้องกันโจร)

## 4. กฎเหล็ก 4 ชั้น ป้องกันการอ้างว่า "ไปถ่ายคอนเทนต์" เพื่อแอบดีลหรือกั๊กบ้าน
1. **เวลาครึ่งวันเช้า/บ่าย พ่วงถ่ายคอนเทนต์ได้อยู่แล้ว:** เอเจนท์ที่มีลูกค้าจริง ลงชื่อลูกค้าตามปกติก็มีเวลา 3.5 ชม. เพียงพอสำหรับถ่ายคลิป
2. **ไม่ลงทะเบียนชื่อลูกค้า = ไม่คุ้มครองสิทธิ์คอมมิชชัน (0 วัน):** หากแอบพาลูกค้าเข้าโดยอ้างว่าไปถ่ายคอนเทนต์ จะไม่มีการล็อกสิทธิ์ผู้ซื้อในระบบ
3. **ลูกค้าผู้ซื้อจริง ชนะ คิวถ่ายคอนเทนต์เสมอ:** ห้ามจองคิวถ่ายคอนเทนต์อย่างเดียวในวันหยุด และหากมีลูกค้าจริงขอเข้าชม ระบบให้สิทธิ์ลูกค้าจริงตัดหน้าทันที (ใช้กั๊กบ้านไม่ได้)
4. **การบ้านบังคับ:** เบิกไปถ่ายคอนเทนต์ต้องส่งลิงก์คลิปที่โพสต์จริงภายใน 48 ชม. มิฉะนั้นถูกหัก Trust Score และตัดสิทธิ์ Fast-Track

## 5. ประเด็นเตรียมสัมภาษณ์ คุณกูล, บัว และพี่ลิลลี่
1. โครงสร้างแรงจูงใจจริงของเอเจนท์ (อะไรทำให้เขาอยากลงพื้นที่ไปถ่ายคอนเทนต์ / เปิดบ้าน)
2. เงื่อนไขค่าแมสเซนเจอร์กรณีส่งกุญแจไปบ้านเอเจนท์ (บริษัทซัพพอร์ตให้ Alpha Agent หรือแบ่งจ่ายอย่างไร)
3. ประสบการณ์จริงของพี่ลิลลี่เรื่องเอเจนท์คืนกุญแจช้าหรือส่งต่อกุญแจกันเองในอดีต
