## 🦈 10. "The Remora Protocol" & Bi-Weekly Delta Sync (ยุทธการเหาฉลาม & รอบอัปเดต 2 ครั้ง/สัปดาห์)

### 📌 คอนเซปต์ "เหาฉลาม" (Zero-Cost / Maximum Leverage):
- ปล่อยให้สตาร์ทอัพอย่าง Homerun ทำหน้าที่เป็น **"ฉลามออกล่า"** ลงทุนค่าระบบ วิ่งเจรจาดีล และคลีนข้อมูลจากธนาคาร

- ข้อมูลและรูปทั้งหมดถูกโฮสต์บน R2 ของเราเอง 100% จึง **ไม่มีการยิงทราฟฟิกกลับไปที่เซิร์ฟเวอร์เขาเลย** ฉลามจึงไม่มีทางรู้ตัว และต่อให้ในอนาคตฉลามปิดระบบ ทรัพย์ทั้งหมดก็ยังอยู่ในคลังศิวาทรัพย์อย่างถาวร

### 📅 ตารางปล่อยของ 2 รอบต่อสัปดาห์ (Bi-Weekly Drop Rhythm):
1. **วันอังคาร (Tuesday Midweek Fresh):** เก็บตกทรัพย์ที่ธนาคารสรุปยอดและปล่อยเข้าระบบช่วงต้นสัปดาห์
2. **วันศุกร์ (Friday Weekend Rush):** เตรียมทรัพย์สดใหม่และดีลลดพิเศษ (Haircut Deals) ให้เอเจนต์ 125 คนนำไปทำคลิป TikTok/ยิงแอดรับคนดูบ้านช่วงวันหยุดเสาร์-อาทิตย์
3. **การตรวจจับส่วนต่างด้วย O(1) Speed:**
   - เช็คค่า `meta.total` ผ่าน API เพียง Request เดียว (< 5 KB ใช้เวลา 1 วินาที)
   - หากตัวเลขขยับ -> สอยเฉพาะแปลงใหม่ที่เพิ่มเข้ามา และตรวจจับแปลงที่ขายออกไป (Delisted) เพื่อมาร์กสถานะ `[ขายแล้ว]`
   - รวบยอดตรวจสอบทั้ง **SCB, SAM, และ TTB** พร้อมกันในรอบเดียว

  - ไม่คลุกฝุ่น แต่สร้างกระแสลมและตาข่ายดักจับผลลัพธ์ทั้งระบบ

  3. **High-Intent Hot Dwell (15–30+ วินาที):** สนใจอย่างแรง (เลื่อนอ่านสเปก, คำนวณค่างวด, เช็กสถานะกุญแจ) -> สามารถยิง Alert เข้า LINE เอเจนต์ผู้ดูแลให้รีบโทรทักปิดการขายได้ทันที

### 🛡️ Web Architecture & Modal Anti-Freeze Fixes:
- **Body Scroll Lock Rule:** ห้ามใช้ `position: fixed !important; top: -...px;` บน `body.modal-open` เด็ดขาด เพราะจะทำให้ `body` กระชากเลื่อนหลุดเฟรมและพื้นหลังแคตตาล็อกหายกลายเป็นสีเทาตัน ให้ใช้เฉพาะ `overflow: hidden !important; overscroll-behavior: contain !important;`
- **Frosted Bokeh Glass:** ฉากหลังโมดอลใช้ `background-color: rgba(15, 23, 42, 0.45); backdrop-filter: blur(6px);` เพื่อความโปร่งแสงหรูหรา มองเห็นการ์ดบ้านด้านหลังเบลอนุ่มนวล
- **Image Error Safeguard:** ทุกแท็ก `<img>` ในโมดอลต้องมี `onerror="this.onerror=null; this.src='...'"` ป้องกันอาการบราวเซอร์ค้างจาก Readyplanet SSL Expired
- **Remove Legacy Outbounds:** ปลดปุ่ม "ดูหน้าเว็บเดิม" ออกจากโมดอล 100% เพื่อป้องกันลูกค้าและเอเจนต์หลุดออกจากระบบ

  3. **การจ่ายผลตอบแทน (Commission):** จ่ายตามสัญญาเมื่อมีการโอนกรรมสิทธิ์สำเร็จ โดย **ไม่ผูกมัดว่าลูกค้าจะต้องได้รับการอนุมัติสินเชื่อเคหะจาก KKP** (ลูกค้าซื้อสดหรือกู้แบงก์อื่น ศิวาทรัพย์ยังได้รับเงินครบถ้วน)
  4. **กรรมสิทธิ์ในข้อมูล (Data Ownership):** KKP ไม่มีสิทธิ์ดูดฐานข้อมูลลูกค้าหรือทรัพย์นอกเหนือจากที่ศิวาทรัพย์อนุมัติใน Feed และระบบสแกนภายนอก (เช่น Zanroo) ยังไม่มีการเปิดใช้งาน

### 2. ลำดับขั้นตอนการปฏิบัติงาน 4 สเต็ปหลังลงนาม (4-Step Executive Action Plan)
```
[ กูลลงนาม MOU ]
       │
       ▼
[ Step 1: ระบบกรองด่านแรกอัตโนมัติ ] ──► (173 แปลง: ราคา ≥ 3M, กทม./ปริมณฑล, พร้อมขาย)
       │
       ▼
[ Step 2: กูลมอบหมายผู้ตรวจเช็ก ] ──► (บัว หรือ พี่ลิลลี่ เปิดหน้าเว็บตรวจ 15-30 หลัง)
       │
       ▼
[ Step 3: ระบบออก XML Feed อัตโนมัติ ] ──► (ออก Feed สด + ปุ่มโหลด Excel/XML ทันที)
       │
       ▼
[ Step 4: กูลส่งมอบลิงก์ให้ IT KKP ] ──► (IT KKP ดึงขึ้นเว็บ Propify จบงานรอบแรก)
```

1. **Step 1: ระบบคัดกรองด่านแรกอัตโนมัติ (Pre-Filtered Inventory):**
   - ระบบหลังบ้านคัดกรองจากฐานทรัพย์ 1,582 รายการ ออกมาได้ **173 รายการ**
   - เกณฑ์: ทรัพย์ศิวาทรัพย์โดยตรง (Direct Listing), ราคา >= 3 ล้านบาท, กทม. และปริมณฑล, และตัดทรัพย์ที่ขายแล้ว (Sold Out) ออก 100%
2. **Step 2: กูลมอบหมายผู้ตรวจเช็กหน้างาน (Curator Verification):**
   - กูลมอบหมายให้ **คุณบัว (Ops)** หรือ **พี่ลิลลี่ (นิติกรรม & กุญแจ)** คัดเลือกบ้านล็อตแรก **15 - 30 หลัง**
   - วิธีทำ: เปิดหน้าเว็บ [`https://assets.siwasup.com/kkp_curation_hub.html`](https://assets.siwasup.com/kkp_curation_hub.html) เลือกชื่อผู้ตรวจ กรอกเลขที่สัญญา และกด **"อนุมัติ (Approve)"** บนเว็บได้ทันที (ใช้เวลา 5-10 นาที ไม่ต้องทำเอกสารใหม่)
3. **Step 3: ระบบสร้าง XML Feed & ส่งออกเอกสารอัตโนมัติ (Automated Feed Generation):**
   - 👁️ **ปุ่ม "ดูตัวอย่าง XML Feed":** พรีวิวโครงสร้าง XML บนหน้าจอ
   - 🌐 **ลิงก์ XML Feed สดทางการ:** `https://assets.siwasup.com/feeds/kkp_properties.xml`
   - 💾 **ปุ่ม "ดาวน์โหลด XML":** สำหรับแนบส่งทางอีเมล
   - 📊 **ปุ่ม "ดาวน์โหลด Excel (CSV with BOM)":** เปิดบน Excel ภาษาไทยไม่เพี้ยน สำหรับใช้เป็นตารางข้อมูลสำรอง
   - 📲 **ปุ่ม "1-Click สรุปส่ง LINE":** สรุปยอดและรายชื่อบ้านล็อตแรกส่งเข้า LINE ผู้บริหาร
4. **Step 4: กูลส่งมอบงานให้ทีมงาน KKP (Handoff to Partner):**
   - กูลส่งลิงก์ XML Feed ทางการ พร้อมแนบไฟล์ Excel สำรองให้คุณเอ๋ / ทีม IT KKP
   - ฝ่าย IT KKP เชื่อมต่อ Feed เข้าสู่ระบบ Propify เป็นอันเสร็จสิ้นกระบวนการส่งมอบล็อตแรกอย่างสมบูรณ์
